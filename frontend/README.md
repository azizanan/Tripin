# TRIPIN Frontend

Frontend TRIPIN menggunakan **React + Vite (JavaScript)**.

## Persyaratan
- Node.js versi LTS
- npm

## Instalasi dan Menjalankan
```bash
cd frontend
npm install
npm run dev
```

Vite secara default berjalan di http://localhost:5173.

## Build
```bash
npm run build
npm run preview
```
